# TALA — Titik phrase library

Folder: assets/audio/fil/shared/titik

Isang recording lang bawat natatanging filename. Ang mga linya ay mula sa kasalukuyang curriculum.

437 reusable recordings. Huwag basahin ang emoji o filename. Ang mga titik at pares ng titik ay kailangang pakinggan at suriin bago gamitin sa pagtuturo.

Para sa paisa-isang titik at pares ng titik, gamitin ang **English na pangalan ng titik**: A = ey, B = bi. English TTS voice ang ginagamit sa mga clip na ito; Filipino pa rin ang mga pangungusap at salita. Tingnan ang [voice notes](../../VOICE_RESEARCH.md).
